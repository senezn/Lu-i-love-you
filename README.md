# Página romântica para namorada 💖

Projeto simples em HTML, CSS e JavaScript para fazer uma surpresa.

## Como personalizar

1. Abra o arquivo `index.html`.
2. Troque os textos da pergunta e da mensagem.
3. Coloque as fotos dela dentro da pasta `assets`.
4. Renomeie suas fotos para:
   - `foto1.jpg`
   - `foto2.jpg`
   - `foto3.jpg`

Se quiser usar mais fotos, duplique os blocos `.foto-card` no `index.html`.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto.
3. Vá em **Settings > Pages**.
4. Em **Branch**, selecione `main` e `/root`.
5. Clique em **Save**.
6. Depois de alguns minutos, o GitHub vai gerar o link da página.

Feito com carinho. 💗
